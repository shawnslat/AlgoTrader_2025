# Claude Code Review Fixes — 2026-07-24 (Phase 1: Correctness)

Pre-change originals of every touched file are in `backups/pre_claude_20260724/`.

## Trader_main_Grok4_20250731.py
1. **Fixed import crash risk** — `DexterGate` was used as a type annotation and instantiated but never imported (NameError on module import). Added `from __future__ import annotations` + guarded `from dexter_gate import DexterGate`.
2. **Backtests no longer corrupt live state** — `generate_signals` gained a `persist=True` flag; `backtest_strategy` passes `persist=False`, so backtests can't overwrite the live `q_table.csv` / `last_decisions.csv` anymore.
3. **Fixed signal broadcast bug** — the Q-learning/MA override was painting the final action across *every* historical row of a ticker (destroying backtest per-day signals). It now writes only the latest row.
4. **Removed live randomness** — ε-greedy exploration (ε=0.05) meant ~1 in 20 live signals was random. Now ε=0 in the signal path.
5. **VIX gating actually works now** — VIX was hardcoded 0 (never fetched), so the `vix_threshold: 25` risk gate never fired. Live cycles now fetch real ^VIX via yfinance (30-min cache, fail-safe to 0). Backtests keep 0 to avoid lookahead leakage.
6. **Dexter veto gate is now enforced** — `execute_trading_logic_live` received `dexter_gate` but never called it. New BUY entries are now blocked when Dexter says avoid (sells/exits never blocked).
7. **Fixed notification NameError** — `send_trade_notification` referenced a global `config` that doesn't exist in the service path; every call silently failed. Now uses a safe lookup.

## bot_service.py
8. **Fixed race condition** — the GUI signals-refresh job and the trading cycle could run `generate_signals` concurrently on the shared Q-table with no lock (CSV/state corruption risk). Both call sites now share `signal_lock`.
9. **Wired the Dexter gate** — the service now constructs a `DexterGate` at init (fail-safe to None) and passes it into `execute_trading_logic_live`, activating fix #6.

## signal_confidence.py
10. **Fixed direction/score contradiction** — dominant direction was chosen by *unweighted* vote while confidence was weight-based, so many weak signals could outvote your strongest one. Direction is now chosen by weighted sums, consistent with the score.
11. **Fixed FinViz miscalibration** — read the wrong key (`flags` vs `risk_flags`, so risk flags were always empty) and treated the 0–100 risk score as 0–5 (any flagged stock saturated to max bearish). Now reads `risk_flags` and uses the 0–100 scale (≥40 = bearish, strength = score/100).

## insider_congress.py
12. **Fixed double-counting** — a dead loop was counting every congressional trade twice in buy/sell counts. Removed; each trade is counted once.

## options_flow.py
13. **Fixed broken negative cache** — a cached "no data" result was indistinguishable from a cache miss, so illiquid/crypto tickers re-hit yfinance every cycle (rate-limit risk). Cache now returns (hit, payload) and honors negative results until TTL.

## dexter_gate.py
14. **Added staleness guard** — if `dexter_bias.json` is older than 24h, the gate logs a warning and fails open instead of enforcing yesterday's decisions.
