# Vault — Memory & Planning

This folder is the persistent brain of the trading system: reviews, decisions,
research, and the roadmap. Claude reads and updates it across sessions
(alongside its own project memory), and you can edit anything here directly.

- `ROADMAP.md` — where the system is and what's next, in order
- `DECISIONS.md` — decision log: what was changed, when, and why
- `SEER_REVIEW_2026-07-24.md` — full code review of the SEER (kalshi_v2) bot
- `RESEARCH_prediction_markets.md` — distilled strategy research (from Shawn's collected articles)
