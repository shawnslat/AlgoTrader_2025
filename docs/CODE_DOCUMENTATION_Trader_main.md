## Overview

This is the main trading bot that combines multiple AI/ML techniques:
- **XGBoost Binary Classifier** for price direction prediction
- **Q-Learning** for action selection refinement
- **Sentiment Analysis** using xAI Grok + NewsAPI
- **Technical Indicators** (25+ features)
- **PDT Protection** via `DayTradeGuard`
- **Dexter AI Gate** for risk veto
- **Live Trading** on Alpaca at 3:55 PM ET daily

The bot operates on daily timeframe data and executes trades 5 minutes before market close to ensure complete daily bars for prediction.

### `download_historical_data(tickers: List[str], polygon_api_key: str, start_date: str, end_date: str)`
**Purpose:** Download full historical data from Polygon.io and save to CSV
**Parameters:**
- `tickers`: List of stock symbols
- `polygon_api_key`: Polygon API key
- `start_date`: Start date (format: "YYYY-MM-DD")
- `end_date`: End date (defaults to today)

**How It Works:**
1. Creates `./data/` directory if missing
2. For each ticker, makes API request to Polygon
3. Rate limited to 5 calls/minute (12-second intervals)
4. Saves each ticker to `./data/{TICKER}.csv`

**API Endpoint:**
```
https://api.polygon.io/v2/aggs/ticker/{ticker}/range/1/day/{start}/{end}
```

**Rate Limiting:**
- Free tier: 5 calls/minute
- Waits 12 seconds between requests
- Handles 429 (rate limit) with retry

**CSV Format:**
```csv
time,open,high,low,close,volume
2024-01-01,150.25,152.10,149.80,151.50,50000000
```

**Error Handling:**
- 401: Unauthorized (invalid API key)
- 429: Rate limited (waits and retries)
- 404: No data (logs warning)

## Feature Engineering

### `engineer_features(df: pd.DataFrame) -> pd.DataFrame`
**Purpose:** Calculate 25+ technical indicators and prepare features for ML model
**Parameters:**
- `df`: Raw market data DataFrame

**Returns:** DataFrame with added feature columns

**Features Calculated (Per Ticker):**

#### Moving Averages
```python
df_ticker['MA10'] = df_ticker['close'].rolling(window=10, min_periods=1).mean()
df_ticker['MA50'] = df_ticker['close'].rolling(window=50, min_periods=1).mean()
```
- **MA10:** 10-day simple moving average
- **MA50:** 50-day simple moving average

#### Momentum Indicators
```python
df_ticker['RSI'] = ta.momentum.RSIIndicator(df_ticker['close'], window=14).rsi()
```
- **RSI:** Relative Strength Index (0-100, overbought >70, oversold <30)

#### MACD (Moving Average Convergence Divergence)
```python
macd_indicator = ta.trend.MACD(df_ticker['close'])
df_ticker['MACD'] = macd_indicator.macd()
df_ticker['MACD_Signal'] = macd_indicator.macd_signal()
df_ticker['MACD_Diff'] = macd_indicator.macd_diff()
```
- **MACD:** Fast EMA - Slow EMA
- **MACD_Signal:** Signal line (9-period EMA of MACD)
- **MACD_Diff:** Histogram (MACD - Signal)

#### Bollinger Bands
```python
bollinger = ta.volatility.BollingerBands(df_ticker['close'])
df_ticker['Bollinger_Upper'] = bollinger.bollinger_hband()
df_ticker['Bollinger_Lower'] = bollinger.bollinger_lband()
```
- **Bollinger_Upper:** Upper band (2 std dev above MA)
- **Bollinger_Lower:** Lower band (2 std dev below MA)

#### Volatility
```python
atr_indicator = ta.volatility.AverageTrueRange(
    df_ticker['high'],
    df_ticker['low'],
    df_ticker['close'],
    window=5
)
df_ticker['ATR'] = atr_indicator.average_true_range()
```
- **ATR:** Average True Range (measures volatility, used for position sizing)

#### Stochastic RSI
```python
stoch_rsi_indicator = ta.momentum.StochRSIIndicator(df_ticker['close'])
df_ticker['Stochastic_RSI'] = stoch_rsi_indicator.stochrsi()
```
- **Stochastic_RSI:** RSI oscillator (0-1 range)

#### Lag Features
```python
df_ticker['Lag1_Close'] = df_ticker['close'].shift(1)
df_ticker['Lag2_Close'] = df_ticker['close'].shift(2)
```
- **Lag1_Close:** Yesterday's close
- **Lag2_Close:** Close from 2 days ago

#### TA-Lib Features (Optional)
If TA-Lib installed:
```python
df_ticker['Momentum'] = talib.MOM(df_ticker['close'], timeperiod=10)
df_ticker['SMA_20'] = talib.SMA(df_ticker['close'], timeperiod=20)
```

#### Volume Change
```python
df_ticker['Volume_Change'] = df_ticker['volume'] / df_ticker['volume'].shift(1)
```
- Ratio of today's volume to yesterday's

#### Buy/Sell Signal Heuristics
```python
df_ticker['buy_signal'] = (
    (df_ticker['RSI'] < 30) &
    (df_ticker['MACD'] > df_ticker['MACD_Signal']) &
    (df_ticker['Stochastic_RSI'] < 0.2)
).astype(int)

df_ticker['sell_signal'] = (
    (df_ticker['RSI'] > 70) &
    (df_ticker['MACD'] < df_ticker['MACD_Signal']) &
    (df_ticker['Stochastic_RSI'] > 0.8)
).astype(int)
```
- Not used for ML, but available for analysis

#### Target Variable
```python
df_ticker['Target'] = (df_ticker['close'].shift(-1) > df_ticker['close']).astype(int)
```
- **Target = 1:** Tomorrow's close > today's close (UP)
- **Target = 0:** Tomorrow's close ≤ today's close (DOWN)

**VIX Merge:**
If `^VIX` data present, merges VIX close as separate feature (market volatility indicator)

**NaN Handling:**
Drops all rows with NaN values (necessary after rolling calculations)

**Minimum Data Requirement:**
Skips tickers with <5 rows after feature engineering

### `prepare_train_test_data(df: pd.DataFrame, selected_features: list)`
**Purpose:** Split data into training and testing sets using time series split
**Parameters:**
- `df`: Full feature-engineered DataFrame
- `selected_features`: List of column names to use as features

**How It Works:**
1. Sorts by date (ensures temporal order)
2. Extracts features (X) and target (y)
3. Splits 80/20 train/test (NOT random split, time-based)

**Split Logic:**
```python
total_samples = len(df)
train_size = int(0.8 * total_samples)

X_train = X.iloc[:train_size]    # First 80%
X_test = X.iloc[train_size:]     # Last 20%
y_train = y.iloc[:train_size]
y_test = y.iloc[train_size:]
```

**Why Time-Based Split?**
Prevents data leakage. Model must predict future based on past, not randomly sampled data.

**Returns:** Tuple of (X_train, X_test, y_train, y_test)

**Example:**
```python
features = ['MA10', 'MA50', 'RSI', 'MACD', ...]
X_train, X_test, y_train, y_test = prepare_train_test_data(df, features)

print(f"Training samples: {len(X_train)}")
print(f"Testing samples: {len(X_test)}")
# Output:
# Training samples: 1200
# Testing samples: 300
```

### `select_action(q_table, state, holding_state, epsilon=0.05) -> str`
**Purpose:** Select trading action using epsilon-greedy Q-learning policy
**Parameters:**
- `q_table`: Q-table DataFrame
- `state`: Current state string
- `holding_state`: 0 or 1
- `epsilon`: Exploration rate (default: 5%)

**How It Works:**

1. **Valid Actions:**
   - If not holding (0): Can `buy` or `hold`
   - If holding (1): Can `sell` or `hold`

2. **Epsilon-Greedy:**
   - 5% chance: Random action (exploration)
   - 95% chance: Best Q-value action (exploitation)

**Formula:**
```python
if random() < epsilon:
    action = random_choice(['buy', 'sell', 'hold'])
else:
    action = argmax(Q[state, valid_actions])
```

**Returns:** Action string ("buy", "sell", or "hold")

**Example:**
```python
action = select_action(q_table, "2-1-1-1-0", holding_state=0)
# Returns "buy" if Q[state, 'buy'] is highest, or random 5% of time
```

## Signal Generation

### `generate_signals(model, data, selected_features, config, q_table, threshold=0.5, positions_snapshot=None) -> pd.DataFrame`
**Purpose:** Hybrid signal generation combining XGBoost predictions with Q-learning refinement
**Parameters:**
- `model`: Trained XGBClassifier
- `data`: Feature-engineered DataFrame
- `selected_features`: Feature columns
- `config`: Config dict
- `q_table`: Q-learning table
- `threshold`: Probability threshold for XGBoost (default: 0.5)
- `positions_snapshot`: Current positions dict

**Returns:** DataFrame with added `Signal` column

**Signal Values:**
- **1:** Buy signal
- **-1:** Sell signal
- **0:** Hold/no action

**Process Flow:**

#### Step 1: XGBoost Prediction
```python
probabilities = model.predict_proba(data[selected_features])[:, 1]
data['Prediction'] = (probabilities >= threshold).astype(int)
```
- Predicts probability of price going UP
- Threshold 0.5 means >50% confidence required

#### Step 2: Signal Conversion
```python
data['Signal'] = data.groupby('ticker')['Prediction'].diff().fillna(0)
```
- Signal triggers on prediction CHANGE:
  - Prediction changes 0→1: Buy signal (1)
  - Prediction changes 1→0: Sell signal (-1)
  - No change: Hold (0)

#### Step 3: VIX Filter
```python
if row.get('VIX', 0) > config.get('vix_threshold', 25):
    data.loc[idx, 'Signal'] = 0  # Block high-volatility trades
```
- Blocks all trades when market volatility (VIX) exceeds threshold

#### Step 4: Q-Learning Refinement
For each ticker:
1. Get current state from indicators
2. Load last decision (if exists)
3. Calculate reward from last action:
   ```python
   delta = (current_price - last_price) / last_price
   if last_action == 'buy':
       reward = delta  # Profit/loss from buy
   elif last_action == 'hold':
       reward = delta if holding else 0.0
   elif last_action == 'sell':
       reward = 0.0
   ```
4. Update Q-table with Bellman equation:
   ```python
   Q[last_state, last_action] += alpha * (reward + gamma * max(Q[new_state]) - Q[last_state, last_action])
   ```
   - **alpha = 0.1:** Learning rate
   - **gamma = 0.9:** Discount factor for future rewards

5. Select new action via `select_action()`
6. Override XGBoost signal if Q-learning disagrees:
   ```python
   if action == 'buy' and xgboost_signal != 1:
       signal = 1  # Q-learning overrides to buy
   elif action == 'sell' and xgboost_signal != -1:
       signal = -1  # Q-learning overrides to sell
   ```

#### Step 5: Save State
- Saves updated Q-table to CSV
- Saves current decisions for next cycle

**Hybrid Logic:**
XGBoost provides initial prediction, Q-learning learns from actual trade outcomes and can override when it has learned a better policy.

**Example Output:**
```python

# 0  AAPL     1         0.5          45     0.2      175.50  # Buy
# 1  MSFT     0        -0.2          72    -0.1      350.25  # Hold
# 2  TSLA    -1         0.1          78    -0.3      250.00  # Sell
```
